# Directory Mapping Configuration

This file defines the directory structure of the king-recreation repository for targeted semantic search queries.

*   **.backlog/docs/**: Houses all project specifications, policy documentation, guidelines, and reference materials.
*   **.backlog/docs/specs/**: Detailed technical specifications for pipeline steps (preprocessing, stem derivation, classification, reconstruction, class macros).
*   **.backlog/docs/policies/**: Definitions of policies for data processing (e.g., blank/missing forms policy).
*   **.backlog/docs/guides/**: Technical guides (e.g., artifacts reference, TeX compilation workflows).
*   **morphology/**: Core Python library implementing Cherokee verb morphology rules, parsing, reconstruction, and phonological/metathesis processes.
*   **morphology/morphemes/**: Definitions and processing of specific classes of morphemes (stems, prefixes, suffixes).
*   **dictionary_pipeline/**: Orchestrates the processing of raw dictionary source files into structured forms using the morphology engine.
*   **dictionary_pipeline/phases/**: Individual pipeline execution phases (e.g., parsing, validation).
*   **dictionary_pipeline/tone/**: Logic for processing, predicting, and validating lexical tone and accentuation.
*   **root-based-dict/**: Code relating to root-based dictionary compilation, entry structuring, and canonical derivation matching.
*   **tex_dictionary/**: Module responsible for formatting dictionary entries into LaTeX syntax and compiling modular TeX files into printable PDFs.
*   **web_viewer/**: Frontend React/web application for visualizing, searching, and interactively exploring classification and reconstruction results (referred to as Frontend Match Explorer).
*   **scripts/**: Command line scripts and utility tools for running localized pipeline tasks, diagnostics, and data migration.
*   **tests/**: Test suite containing unit and integration tests for morphology rules, pipeline stages, and validation.
*   **data/**: Raw CSV/JSON inputs, reference data files (e.g., King's original class tables, tone classes), and metadata.
*   **curated/**: Curated dataset files, manually corrected forms, and verified linguistic mappings.
*   **artifacts/**: Outputs generated by pipeline steps.
*   **artifacts/data/**: Intermediate and final CSV/JSON datasets (e.g., stems, matches, reconstructed dictionary data).
*   **artifacts/reports/**: Generated analysis reports, coverage metrics, and near-miss statistics.
*   **artifacts/visualizations/**: Matplotlib/Seaborn output plots, heatmaps, and charts.
*   **artifacts/debug/**: Diagnostic outputs, error logs, and near-miss detailed spreadsheets.
*   **artifacts/tex/**: Compiled LaTeX artifacts including modular `.tex` source files and the final compiled print-ready PDF.
