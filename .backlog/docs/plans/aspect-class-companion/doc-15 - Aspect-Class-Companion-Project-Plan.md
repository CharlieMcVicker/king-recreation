---# Aspect Class Companion: Project Plan & Implementation Reference

## Context and Motivation
This project created a companion document to the Cherokee root-based dictionary (`main.pdf`), specifically tailored for Cherokee second-language learners. The companion document demystifies complex aspect morphemes (verb classes) by systematically detailing their surface forms across all conjugations, alongside prototypical example words ("mascots"), recorded variants, and exact cross-references to the main dictionary.

During planning, several key decisions were made to ensure the output is both pedagogically robust and technically sound:
1. **Mascot Selection:** Rather than picking random verbs for illustrative purposes—which can lead to unstable builds—we use a curated file ([aspect_class_mascots.csv](../../../../curated/aspect_class_mascots.csv)) that maps a specific `corpus_id` to an aspect class. If a manual mascot has not been chosen yet, we fallback deterministically to the alphabetically first occurring verb by its present form.
2. **Realistic Variant Scope:** For a given aspect class, there are numerous possible configurations of prefixes and suffixes. To prevent combinatorial explosion and confusing the learner, we strictly document only the variant combinations that *actually occur* in our corpus dataset.
3. **Robust Page Indexing:** To avoid deeply coupling Python logic to LaTeX page breaking internals, we extract accurate page numbers by parsing `main.toc` (the Table of Contents generated by compiling `main.tex`). Because entries in `main.toc` contain deeply nested brackets, our parsing module combines light regular expressions with an explicit character iteration approach tracking `{}` nesting depth.
4. **Visual Consistency and Clarity:** The companion uses the identical LaTeX preamble (fonts, geometry, styling packages) as the main dictionary. Conjugation layouts emphasize the morphological segments by distinctly color-coding the pronouns (Red: Set A, Blue: Set B, Purple: Person-to-Person) and bolding the aspect ending.

## Implemented Architecture

The companion generation is structured into modular subcomponents:

### 1. Data Infrastructure & Mascot Resolution
- Loaded via [companion_data.py](../../../../tex_dictionary/companion_data.py), which handles loading aspect classes from `data/classes.csv` and frequencies from `artifacts/reports/class_match_counts.csv`.
- Mascot mapping is loaded from [aspect_class_mascots.csv](../../../../curated/aspect_class_mascots.csv).
- Fallback mascot selection is implemented in `select_deterministic_mascot` in [companion_data.py](../../../../tex_dictionary/companion_data.py#L107-L117).

### 2. Page Number Extraction (TOC Parser)
- The LaTeX TOC parser is implemented in `tex_dictionary/toc_parser.py`. It reads `artifacts/tex/main.toc` and parses contents line entries to map verb classes to page numbers.

### 3. TeX & Table Generation
- Main formatting and layout is in [companion_generator.py](../../../../tex_dictionary/companion_generator.py).
- Tables are generated using `Tabularx` layout, color-coding pronouns and bolding endings in `format_segmented_verb` in [companion_generator.py](../../../../tex_dictionary/companion_generator.py#L88-L231).

### 4. Pipeline Integration
- Integrated in `tex_dictionary/__main__.py`, where `generate_companion_tex` is triggered after `main.tex` is compiled and `main.toc` is stable.
