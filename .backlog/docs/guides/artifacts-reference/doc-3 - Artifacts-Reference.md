This guide describes the active outputs generated by the dictionary analysis pipeline. Artifact paths are defined programmatically in [paths.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/paths.py).

## Corpora (`artifacts/corpora/`)

Intermediate cleaned data files representing stages of ending and prefix stripping.

| File | Purpose | Generated By |
| :--- | :--- | :--- |
| `corpus.csv` | Cleaned and respelled CED/CN dictionary data (base for analysis). | [preprocess_ced/__init__.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/phases/preprocess_ced/__init__.py) |
| `corpus_raw.csv` | Raw processed corpus data before manual patches. | [preprocess_ced/__init__.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/phases/preprocess_ced/__init__.py) |
| `corpus_no_asp.csv` | Verb forms with identified endings removed, ready for prefix stripping. | [identify_aspect_classes/__init__.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/phases/identify_aspect_classes/__init__.py) |
| `corpus_no_pre_no_asp.csv` | Verb forms with both prefixes and aspect endings stripped. | [identify_prefixes/__init__.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/phases/identify_prefixes/__init__.py) |
| `corpus_to_cnd.csv` | Mapping from pipeline corpus IDs to original CND entries. | [preprocess_ced/__init__.py](file:///Users/charlesmcvicker/code/king-recreation/dictionary_pipeline/phases/preprocess_ced/__init__.py) |

## Visualizations (`artifacts/visualizations/`)

Generated plots and charts for trend analysis.

- `class_distribution_reconstructs_full.png` / `class_distribution_reconstructs_filtered.png`: Distribution of reconstructed verbs.
- `class_distribution_all_full.png` / `class_distribution_all_filtered.png`: Distribution of all matched verbs.
- `class_match_histogram.png`: Propensity of class matching.
- `verb_coverage.png`: Combined plot showing match counts and system coverage %.
- `root_ambiguity_histogram.png`: Distribution of root sharing across the corpus.
- `macro_variants/*.png`: Bar charts showing combination frequency for each macro class.
