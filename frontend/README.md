# King Recreation Frontend: Match Explorer

This is a **Next.js (App Router)** frontend designed to explore, visualize, and analyze the linguistic match data generated by the `king-recreation` Python module.

## 🚀 Recommended Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/) or [Chart.js](https://www.chartjs.org/) (for interactive versions)
- **CSV Parsing**: [Papa Parse](https://www.papaparse.com/) or `csv-parse`

## 🛠️ Data Architecture

The application should run in the same repository as the analysis scripts. Using Next.js Server Components, we can read data directly from the parent directories without duplicating files.

### Artifact Access Strategy
Server-side routes or components will use the `fs` module to read:
- `../artifacts/analysis/*.json` & `../artifacts/analysis/*.csv`
- `../artifacts/matches.csv` (Note: This file is large, ~2.3k rows)
- `../data/king_classes.csv`
- `../artifacts/corpus.csv`

### API Layer
Implement an internal API or Server Actions to provide filtered/structured data to the client:
- `getClasses()`: Parses `king_classes.csv`.
- `getMatchesByClass(className)`: Filters `matches.csv` for a specific class.
- `getComparison(classA, classB)`: Computes intersections/differences server-side.

## 🖼️ Major Views

### 1. Dashboard (The High-Level Overview)
**Goal**: Immediate insight into the "health" of the analysis.
- **Top Metrics**: Render "Coverage %" for all 4 match modes (Strict/Loose x Full/Ending) from `verb_coverage.json`.
- **Static Assets**: Display the generated PNG charts from `artifacts/analysis/` (e.g., `verb_coverage.png`, `class_distribution_filtered.png`).
- **Match Table**: A searchable table of `class_match_counts.csv` showing how many verbs each class captures.

### 2. Class Explorer (The Deep Dive)
**Goal**: Understand why a specific class is or isn't matching.
- **Selector**: A sidebar or dropdown to select a class from King's system.
- **Pattern View**: Display the specific patterns (present, imperfective, etc.) for that class from `king_classes.csv`.
- **Match Gallery**: List all rows from the corpus that result in a "Full Match".
- **Near-Miss Diagnosis**: 
    - Use `class_near_misses.csv` to show the failure rates of individual verb forms (e.g., "This class fails on Imperative 60% of the time").
    - List "Near Match" verbs (where scope is `ending` but not `full`).

### 3. Comparison Tool (Class Intersection)
**Goal**: Compare the "reach" of different classes.
- **Selection**: Choose two classes (e.g., `Ia` vs `Id`).
- **Venn Diagram / Split View**:
    - **A only**: Verbs matched by Class A but not B.
    - **Both**: Verbs matched by both.
    - **B only**: Verbs matched by Class B but not A.
- **Diff View**: Highlight specific forms that cause a verb to match one class but fail another.
