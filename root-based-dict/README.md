# Root-Based Dictionary

This is a focused frontend application that powers the Root Dictionary view for the Cherokee linguistic analysis project.

## Purpose

This application is a specialized version of the main Match Explorer, focusing exclusively on browsing Cherokee verb roots and their associated reconstructable verbs.

## Key Features

- **Root Browse**: View a grid of all attested roots.
- **Root Details**: Deep dive into specific roots, including associated verbs, definitions, and class information.
- **Focused Navigation**: Simplified interface with only root-related views.

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
