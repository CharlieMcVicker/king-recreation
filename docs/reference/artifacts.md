# Artifacts Reference

The `artifacts/` directory contains all outputs generated by the analysis pipeline.

## Directory Structure

| Subdirectory      | Contents                                                     | Examples                                                                                |
| :---------------- | :----------------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| `data/`           | Intermediate CSV data files used as pipeline inputs/outputs. | `corpus.csv`, `matches.csv`, `stem_corpus.csv`                                          |
| `reports/`        | Human-readable analysis summaries and validation reports.    | `consistency_analysis.csv`, `reconstruction_report.csv`, `stem_derivation_failures.csv` |
| `visualizations/` | Generated plots and charts.                                  | `class_distribution.png`, `near_miss_heatmap.png`                                       |
| `debug/`          | Error logs and raw dump files for debugging.                 | `near_misses_*.csv`                                                                     |
