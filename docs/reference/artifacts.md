# Artifacts Reference

The `artifacts/` directory contains all outputs generated by the analysis pipeline. Artifacts are organized by their stage in the pipeline and their intended use.

## Data (`artifacts/data/`)

Intermediate data files used by the pipeline or exported for the frontend.

| File                                  | Purpose                                                                | Generated By                |
| :------------------------------------ | :--------------------------------------------------------------------- | :-------------------------- |
| `corpus.csv`                          | Cleaned and respelled CED/CN dictionary data (base for analysis).      | `preprocess_ced.py`         |
| `matches_initial.csv`                 | Raw potential matches found by applying ending patterns.               | `classify_verbs.py`         |
| `endings_stripped_corpus.csv`         | Verb forms with identified endings removed, ready for stem derivation. | `classify_verbs.py`         |
| `derived_roots.csv`                   | Roots identified by removing pronominal prefixes from stripped forms.  | `derive_stems.py`           |
| `matches_validated.csv`               | Final matches that pass both ending classification and reconstruction. | `reconstruct_from_roots.py` |
| `reconstructable_verbs.json`          | Fully serialized verb data used by the frontend.                       | `reconstruct_from_roots.py` |
| `classes_expanded.json`               | Snapshot of the class patterns used during the last run.               | `reconstruct_from_roots.py` |
| `root_ids.csv`                        | Unique identifiers for roots based on h-grade and g-grade.             | `group_hierarchical.py`     |
| `validated_reconstructable_roots.csv` | User-validated root selections and configurations.                     | `reconstruct_from_roots.py` |

## Reports (`artifacts/reports/`)

Human-readable analysis summaries and validation reports.

| File                             | Purpose                                                               | Generated By                |
| :------------------------------- | :-------------------------------------------------------------------- | :-------------------------- |
| `class_match_counts.csv`         | Aggregated match statistics per class.                                | `analyze_matches.py`        |
| `class_near_misses.csv`          | Pass rates for stem-final checks, highlighting common failure points. | `analyze_matches.py`        |
| `consistency_analysis.csv`       | Detailed report on root/stem consistency across verb forms.           | `reconstruct_from_roots.py` |
| `macro_variant_data.json`        | Usage statistics for macro class variants and slot options.           | `analyze_matches.py`        |
| `reconstruction_report.csv`      | Success/failure summary for every reconstruction candidate.           | `reconstruct_from_roots.py` |
| `reconstruction_failures.csv`    | Detailed breakdown of mismatching forms for failed reconstructions.   | `reconstruct_from_roots.py` |
| `reconstruction_validation.json` | High-level validation stats and failure list.                         | `reconstruct_from_roots.py` |
| `root_ambiguity_counts.csv`      | Distribution of verbs per unique root pair (identifies ambiguity).    | `analyze_matches.py`        |
| `stem_derivation_failures.csv`   | Verbs where the system could not successfully remove prefixes.        | `derive_stems.py`           |
| `unmatched_verbs_strict.csv`     | Verbs that failed to match any class under strict rules.              | `analyze_matches.py`        |
| `unmatched_verbs_loose.csv`      | Verbs that failed to match any class even under loose rules.          | `analyze_matches.py`        |
| `verb_coverage.json`             | JSON data backing the coverage visualizations.                        | `analyze_matches.py`        |

## Visualizations (`artifacts/visualizations/`)

Generated plots and charts for trend analysis.

| File Pattern                   | Description                                                      | Generated By            |
| :----------------------------- | :--------------------------------------------------------------- | :---------------------- |
| `class_distribution_*.png`     | Charts showing number of verbs matched by each class.            | `visualize_analysis.py` |
| `near_miss_heatmap_*.png`      | Heatmaps showing where classes tend to fail stem-final checks.   | `visualize_analysis.py` |
| `verb_coverage.png`            | Combined plot showing match counts and system coverage %.        | `visualize_analysis.py` |
| `root_ambiguity_histogram.png` | Distribution of root sharing across the corpus.                  | `visualize_analysis.py` |
| `class_match_histogram.png`    | Histogram of "class propensity" (how many verbs use each class). | `visualize_analysis.py` |
| `macro_variants/*.png`         | Bar charts showing combination frequency for each macro class.   | `visualize_analysis.py` |

## Connections (`artifacts/connections/`)

Files defining relationships between roots and other morphemes.

| File Pattern                   | Description                                            | Generated By            |
| :----------------------------- | :----------------------------------------------------- | :---------------------- |
| `root_connections.csv`         | Relationships between roots and derivational suffixes. | `group_hierarchical.py` |
| `post_root_connections.csv`    | Relationships involving post-root morphemes.           | `group_hierarchical.py` |
| `middle_voice_connections.csv` | (Deprecated) Old middle voice connection mappings.     | `group_hierarchical.py` |

## Debug (`artifacts/debug/`)

The `debug/` directory is used for ad-hoc error logs and raw dump files during development.
