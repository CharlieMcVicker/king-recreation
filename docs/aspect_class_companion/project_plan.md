# Aspect Class Companion: Project Plan

## Context and Motivation
This project aims to create a companion document to the Cherokee root-based dictionary (`main.pdf`), specifically tailored for Cherokee second-language learners. The companion document seeks to demystify complex aspect morphemes (verb classes) by systematically detailing their surface forms across all conjugations, alongside prototypical example words ("mascots"), recorded variants, and exact cross-references to the main dictionary.

During planning, several key decisions were made to ensure the output is both pedagogically robust and technically sound:
1. **Mascot Selection:** Rather than picking random verbs for illustrative purposes—which can lead to unstable builds—we will use a curated file (`curated/aspect_class_mascots.csv`) that maps a specific `corpus_id` to an aspect class. If a manual mascot has not been chosen yet, we will fallback deterministically to the alphabetically first occurring verb (by its present form).
2. **Realistic Variant Scope:** For a given aspect class, there are numerous possible configurations of prefixes and suffixes. To prevent combinatorial explosion and confusing the learner, we will strictly document only the variant combinations that *actually occur* in our corpus dataset.
3. **Robust Page Indexing:** To avoid deeply coupling Python logic to LaTeX page breaking internals, we will extract accurate page numbers by parsing `main.toc` (the Table of Contents generated by compiling `main.tex`). Because entries in `main.toc` contain deeply nested brackets, our parsing module will combine light regular expressions with an explicit character iteration approach tracking `{}` nesting depth.
4. **Visual Consistency and Clarity:** The companion will use the exact identical LaTeX preamble (fonts, geometry, styling packages) as the main dictionary. Conjugation layouts will emphasize the morphological segments by distinctly color-coding the pronouns (Red: Set A, Blue: Set B, Purple: Person-to-Person) and bolding the aspect ending.

## Detailed Implementation Phases

To iteratively build the `companion.tex` generation pipeline, we will build small, composable modules that culminate in the final build step.

### Phase 1: Data Infrastructure & Orchestration
**Goal:** Gather all necessary data sets and define the target verb forms.
- Create the template `curated/aspect_class_mascots.csv`.
- Implement a module to load all aspect classes and their surface forms from `data/classes.csv`.
- Implement logic to load class frequencies from `artifacts/reports/class_match_counts.csv` and sort the aspect classes from most frequent to least frequent.
- Prepare the fallback mechanism for deterministic mascot selection.

### Phase 2: Accurate Page Number Extraction
**Goal:** A standalone module capable of scraping verb locations from LaTeX TOC files.
- Read `artifacts/tex/main.toc`.
- Build a robust parser that streams each character and tracks depth of `{` and `}` to accurately isolate `\contentsline` attributes.
- Return a mapping: `verb_class` -> `Set(page_numbers)`.

### Phase 3: Mascot Variant Resolution
**Goal:** Determine which variants of a class actually appear in the corpus and resolve a mascot verb for each.
- Implement logic to query the dictionary/corpus data for words grouped implicitly or explicitly by the current aspect class.
- Compute all observed distinct combinations of variant morphologies attached to this class.
- For every valid variant combination, lookup the designated `corpus_id` in `aspect_class_mascots.csv`. If not found, run an alphabetical sort on present tense forms among the subset of matching corpus words.
- Retrieve the `ReconstructableVerb` representation for the determined mascot verb.

### Phase 4: TeX Layout & Table Generation
**Goal:** Generate the pedagogical tables for a specific class.
- Write a submodule to generate the variant tables. For each variant combination, emit two grouped rows:
  - **Row 1:** The class name (colored/tagged with its variant) followed by the raw aspect endings across all conjugations (Present, Imperfective, Perfective, Imperative, Infinitive). Base variants will list all endings; derived variants will list only ending structures modified by the derivations (leaving others blank).
  - **Row 2:** The selected mascot verb's definition and its page reference in the first column. The remaining columns contain all five reference forms of the conjugated word, with pronoun segments color-coded (Red: Set A, Blue: Set B, Purple: Person-toPerson) and aspect endings set in **boldface**.
- Additionally, emit the TOC-style catalog beneath the table: listing every verb matching the class and variant combination (e.g., `verb_to_tex` form followed by the extracted page number).

### Phase 5: Pipeline Integration & Compilation
**Goal:** Wire the companion generation seamlessly into the dict builder.
- Inside `tex_dictionary/__main__.py`, trigger `generate_companion_tex()` strictly *after* `xelatex main.tex` finishes its final compilation (ensuring `main.toc` is perfectly stable and up-to-date).
- Share the identical preamble configuration from `main.tex`.
- Automatically invoke `xelatex` on `companion.tex` to yield `companion.pdf`.
